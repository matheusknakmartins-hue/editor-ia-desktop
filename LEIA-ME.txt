EDITOR DO NEIS — Windows x64 — versão portátil 1.0

1. Extraia TODO o ZIP para uma pasta local.
2. Abra EDITOR DO NEIS.exe dentro da pasta extraída.
3. Não mova somente o EXE: ele precisa das pastas e DLLs ao lado.
4. Adicione pastas contendo exatamente três vídeos cada.
   Ordem natural do nome: cena1, cena2, cena3 (ou 1, 2, 3).
5. Ajuste as velocidades, gere a prévia e exporte.

Imagens para o Flow:
- Clique em "Identificar produtos nas imagens" e selecione uma quantidade
  par de imagens, de 2 a 20 (até 10 produtos). Os nomes podem ser aleatórios.
- O modelo visual DINOv2 Small sugere pares por semelhança visual.
  Confira as miniaturas: produtos parecidos podem ser confundidos.
- Defina qual imagem é a Cena 1 e qual gera as Cenas 2/3. O modelo não
  identifica automaticamente qual imagem veio do ChatGPT ou do Flow.
- Use as listas para trocar imagens entre produtos e o botão de inverter
  para trocar a posição das duas cenas. Clique em "Confirmar pares e cenas".
- A opção manual continua disponível: adicione um produto por vez,
  selecionando primeiro a Cena 1 e depois a imagem das Cenas 2/3.
- A numeração dos produtos segue a ordem em que são adicionados.
- Exporte para uma pasta: será criada uma subpasta Imagens-Flow-...
- Os nomes começam pela sequência: todas as Cenas 1 dos produtos,
  depois todas as Cenas 2/3, mantendo a mesma ordem dos produtos.
- Exemplo com dois produtos: 001_Cena-1_Prod-01.png,
  002_Cena-1_Prod-02.png, 003_Cenas-2-3_Prod-01.png,
  004_Cenas-2-3_Prod-02.png. A extensão original é preservada.
- São aceitos PNG, JPG/JPEG e WebP. Os originais não são alterados.
- Selecione os arquivos no Flow pela ordem do nome. Não há envio automático.
- A lista de imagens fica disponível até fechar o editor.

Modelo visual local:
- A análise de imagens não usa API paga nem a chave AssemblyAI.
- No primeiro uso é necessário internet para baixar o modelo gratuito de
  https://huggingface.co/Xenova/dinov2-small (DINOv2, licença Apache 2.0).
- São baixados apenas arquivos públicos do modelo. As imagens não são
  enviadas. O download é conferido por SHA-256 antes de usar o modelo.
- O modelo fica em %APPDATA%/editor-do-neis/models/dinov2-small. Nos usos
  seguintes a análise funciona offline, usando o processador do computador.
- Aproveita o Python, NumPy, ONNX Runtime e FFmpeg incluídos no pacote.

Configurações:
- AssemblyAI: informe sua própria chave e clique Salvar chave.
  A chave é protegida pelo Windows para o usuário atual.
  A transcrição envia áudio ao AssemblyAI e pode gerar cobrança.
- Desmarque AssemblyAI para detecção local, sem chave ou internet.
- Prévia/exportação incluem cortes, aceleração, redução de ruído e seta.
- Exportar todos copia os vídeos prontos sem renderizá-los de novo.
- Remover da fila não exclui os arquivos originais.

Requisitos: Windows 10/11 x64. Não é uma versão nativa ARM64.
Python e FFmpeg estão incluídos. Para erro de DLL do mecanismo local,
instale o Microsoft Visual C++ Redistributable x64 incluído em
Suporte/VC_redist.x64.exe (instalador oficial Microsoft).

Os dados ficam em %APPDATA%/editor-do-neis. A fila começa vazia a cada
abertura; chave salva e prévias no disco são preservadas.
Não há atualização automática. Não inclui sua chave nem seus vídeos.

LIMITAÇÃO DE VALIDAÇÃO:
O pacote foi montado no macOS com binários Windows x64 oficiais.
Foram verificados estrutura, executáveis e testes automatizados de lógica.

versão Windows para validação, não uma versão homologada nesse sistema.
